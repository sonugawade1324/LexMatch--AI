LEXMATCH AI WEBSITE - SETUP

1. Extract this ZIP file.
2. Keep all HTML, CSS and JS files in the same folder.
3. Open index.html in a browser, or preferably open the folder in VS Code and run it with Live Server.
4. Use Register to create a demo account, then Login. Data is saved only in that browser using localStorage.

PAGES
index.html - Home
about.html - About
legal_topics.html - Legal Topics
chatbot.html - Chatbot demo
faq.html - FAQ
contact.html - Contact form
feedback.html - Feedback form
login.html / register.html - Demo account pages
user_dashboard.html - User dashboard
admin_dashboard.html - Static admin dashboard
profile.html - Profile
home_alternative.html - Second home-page design kept from the supplied files

IMPORTANT
This is a connected front-end college-project prototype. Registration, login, profile, feedback and contact data are stored in the current browser only. localStorage is not a secure database and does not sync between devices/users. Do not use real passwords or sensitive personal information. The chatbot is still a scripted demo; it is not connected to a live AI model or legal database. For real database connectivity, add a backend (for example PHP + MySQL, or Node.js + a database) and secure authentication/API endpoints.
